# Academy 课件风配图

目标：画出来的图和 Academy 课件配图放在一起分不出来，内容换成我们自己的（多半是中文）。参照的是 MCP 两门课和《使用 Claude API 构建》的幻灯片配图，下面每条样式都是在原图上量出来的。偏离其中任何一条，放在原图旁边就会露馅。

## 这套样式

- **一张图一件事。** 像幻灯片的一页：2–6 个主元素，四周大片留白；要读者记住的结论放进底部陶土结论条或一张便签，不写成小字注释。
- **字大。** 画布宽 1920（高度随内容），框名 41px，连线说明 27px，最小 24px。缩到正文列宽（约 700px）后框名约 15px，和正文差不多大，这是这套图看着清楚的主要原因。
- **一种衬线字。** 图里的字都是 Lora：名称用常规体，关键句加粗，英文连线说明用斜体。标题、步骤条、消息表用 Poppins 半粗；代码是黑底面板上的陶土色等宽字。
- **五种颜色。** 米黄是我方、用户、客户端；陶土是线上传递的消息、助手、结论；深陶土是当前步骤、Claude 大块；浅灰是参与者、便签；暖灰是大块背景、还没到的步骤。字和主线近黑，图里没有蓝和绿。
- **线分两级。** 主消息是 4.5px 黑线配实心三角箭头，一张图只留给真正要讲的一两条；其余在时序图里是 2.6px 浅灰线（`faint`），在结构图、链路图里是框与框之间的 4px 深灰线（`gray`）。时序图的生命线是灰色虚线。
- **压线标签。** 线上传的东西的名字（协议消息名 `CallToolRequest`、`tool_use`，或链路图里的“节点”“线路”）放进直角陶土框，框边压在箭头上；解释写在框外。
- **中文正体。** 中文落到 Noto Serif SC / Noto Sans SC，一律正体（渲染脚本会自动改）。代码名、字段名、消息类型名保留英文原样，其余叫法照目标文档已有的说法。

具体数值都在 `assets/academy.css`，它是唯一的出处：SVG 里只写那里的类名，渲染时脚本把样式和字体注入。diagram-design 技能的版式规则（小字号、细线、标签不压线、小圆角）和这套样式相反，画这种图时只用本技能的类和构件。

## 步骤

1. **定内容。** 用一句话写下这张图要让读者看懂什么，列出元素：参与者、框、消息、结论。主元素超过 6 个就拆成两张。从 [构件](references/components.md) 里选版式：时序图、横向链路、容器加压线标签、双栏大块、卡片排、步骤条加消息表、代码面板。
   完成标准：一句话、元素清单、选定的版式都写下来了。
2. **写 SVG。** 复制 `assets/template.svg`，存到第 4 步说的图片目录，按 1920 宽的坐标摆构件（高度随内容，见 components.md 的“画布”），尺寸和间距照 components.md。`examples/` 里有三张一比一量出来再汉化的范例，拿不准比例时照它们摆。中文按每字 1em、英文每字 0.5em 估宽度：框宽至少是字宽加两边各 0.6em，放不下就换行，不缩字号。
   完成标准：SVG 里除了 template 自带的部分，只有类名和坐标，没有颜色、字体、字号。
3. **渲染自检。** 跑本技能目录下的 `node <本技能目录>/scripts/render.mjs <图>.svg`（要 Node 22 以上和 Chrome：脚本用 Node 自带的 WebSocket 驱动无头 Chrome；找不到 Chrome 时把环境变量 `CHROME` 设成浏览器路径）。中文默认用本机装的 Noto Serif SC / Noto Sans SC；项目自托管了这两种字体时，把环境变量 `CJK_FONTS_CSS` 设成那份 `@font-face` CSS 的路径，图里的中文就和正文同一套字形。它先检查字体、出画布、顶到框、文字重叠、字号和调色板，再在 SVG 旁边写出同名 WebP，PNG 预览写到临时目录（路径会打印出来）。用 Read 打开预览，对照“这套样式”逐条看，改完再渲染。
   完成标准：报告里没有 ERROR；每条 WARN 要么改掉，要么说得出保留的理由；预览里每条样式都对得上。
4. **放进文档。** WebP 和 SVG 源文件放在同一个图片目录，SVG 留着以后改图用；项目有自己的图片目录约定就照它来。正文引用 WebP：`![一句话说明](<图片目录>/<图名>.webp)`。SVG 只是源文件，它不带字体，直接当图片引用会变回系统字体。
   完成标准：文档里引用的路径存在，图放在讲到它的那段话之后。

## 复刻或汉化原图

给了 Academy 原图要重画时，先读 [复刻流程](references/replicate.md)：在原图上量出颜色、字号和位置，按原图坐标一比一重画，用差值图核对到几乎全黑，再换中文。原图只在本地比对用，项目里只提交自己画的 SVG 和导出的 WebP。

## 报告

- 新增的 SVG、WebP 路径，以及在哪篇文档的哪一段引用；
- 渲染检查保留下来的 WARN 和理由；
- 复刻时：差值图的路径，还有哪些地方没对齐。
